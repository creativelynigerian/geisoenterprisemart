# GEISO ENTERPRISE – The Place of Exquisite Fashion

> **Designed and Developed by CCYI GLOBAL ENTERPRISE**

An authentic luxury African couture and handcrafted braided wig e-commerce web platform. Built with modern semantic HTML5, pure CSS3 design system, and responsive JavaScript.

---

## 🌟 Key Features

- **Royal African Couture Catalog**: Over 40 unique handcrafted pieces spanning Senator styles, bespoke Jalamia, luxury Silk Adire Bubu gowns, and Yoruba Aso-Oke wedding sets.
- **Handmade Braided Wigs**: Full lace frontals, micro twists, and knotless box braid wigs with natural scalp effect.
- **Interactive Shopping Bag**: Slide-out cart drawer with live subtotal calculation, quantity steppers, and `localStorage` persistence.
- **Free Shipping Progress Meter**: Dynamic tracker celebrating orders qualifying for free UK express delivery (£100 threshold).
- **Promo Coupon System**: Built-in 15% discount voucher engine (`GEISO15`) with 1-click clipboard copy.
- **Instant Search & Category Filters**: Real-time filtering by category, search keywords, price range, and rating.
- **Quick View Modal & WhatsApp Ordering**: Fast attire inspection with direct 1-click WhatsApp order dispatch.
- **Mobile Responsive Drawer**: Fluid experience optimized across all mobile, tablet, and desktop screens.

## 🚀 Deploying to Vercel via GitHub

1. **Create a GitHub Repository**:
   - Go to [github.com/new](https://github.com/new) and name your repository (e.g., `geiso-enterprise`).
   - Leave it public or private.

2. **Push or Upload the Files**:
   - If using Git:
     ```bash
     git init
     git add .
     git commit -m "Initial commit: GEISO Enterprise storefront"
     git branch -M main
     git remote add origin https://github.com/<YOUR-USERNAME>/geiso-enterprise.git
     git push -u origin main
     ```
   - Or drag-and-drop the files (`index.html`, `vercel.json`, `css/`, `js/`) directly on GitHub's web interface.

3. **Deploy on Vercel**:
   - Go to [vercel.com/new](https://vercel.com/new).
   - Under **Import Git Repository**, select your `geiso-enterprise` repository.
   - Click **Deploy**.
   - Your site will be live instantly with a free SSL certificate and a custom `*.vercel.app` domain!
